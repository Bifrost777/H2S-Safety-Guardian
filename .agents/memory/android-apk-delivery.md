---
name: Android APK delivery
description: Replit's current boundary for Expo Android preview and standalone APK export.
---

Replit supports building and previewing Expo Android apps, including testing through Expo Go, but it does not directly export a standalone Android APK file.

**Why:** Official Replit documentation states that Android preview is supported while built-in publishing/export for Google Play or a standalone APK is not.

**How to apply:** Finish and verify the Expo app in Replit, then explain the external Android build requirement rather than promising an APK artifact from the workspace.
